# AI Tribrid Transportation Safety System

## Overview

The AI Tribrid Transportation Safety System is an intelligent transportation safety framework that integrates Convolutional Neural Networks (CNN), You Only Look Once (YOLO), and Artificial Neural Networks (ANN) to provide comprehensive transportation risk assessment. The system combines driver monitoring, traffic analysis, and predictive risk estimation within a unified Streamlit-based web application.

The framework analyzes driver alertness using CNN, estimates traffic density through YOLO-based vehicle detection, and predicts transportation risk using ANN-based regression. The outputs generated by these modules are integrated through a Hybrid Risk Fusion Engine to provide an overall transportation safety assessment.

---

## Features

* Driver Drowsiness Detection using CNN
* Vehicle Detection and Traffic Density Estimation using YOLOv8
* Transportation Risk Prediction using ANN
* Hybrid Risk Fusion Engine
* Interactive Streamlit Dashboard
* Real-Time Traffic Analysis
* Transportation Safety Assessment
* User-Friendly Web Interface

---

## System Architecture

The proposed framework consists of three primary Artificial Intelligence modules:

### CNN Module

* Driver eye image analysis
* Drowsiness detection
* Alertness assessment

### YOLO Module

* Vehicle detection
* Vehicle counting
* Traffic density estimation

### ANN Module

* Transportation risk prediction
* Environmental parameter analysis
* Safety score generation

The outputs generated by these modules are combined using a Hybrid Risk Fusion Engine to generate the final transportation risk assessment.

## Project Workflow

1. Upload Driver Eye Image
2. Upload Traffic Video
3. Enter Transportation Parameters
4. CNN predicts Driver Drowsiness
5. YOLO estimates Traffic Density
6. ANN predicts Transportation Risk
7. Hybrid Risk Fusion Engine combines outputs
8. Final Transportation Safety Assessment is displayed
